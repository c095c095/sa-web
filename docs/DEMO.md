# คู่มือสาธิตระบบตรวจและส่งมอบบ้าน

## เปิดบนเครื่องสาธิต

ต้องมี Node.js 24, npm, MariaDB 10.11 และ Chrome หรือ Edge สำหรับสร้าง PDF ใหม่ บน Windows ใช้ MariaDB จาก XAMPP ได้ เปิด MariaDB และรันจากโฟลเดอร์ `sa-web` ใน PowerShell หรือ Terminal

```sh
npm ci
npm run demo:setup
npm run demo:start
```

เปิด [หน้าเข้าสู่ระบบสาธิต](http://127.0.0.1:3010/login) แล้วกดชื่อบทบาทเพื่อเข้าใช้งาน หากจะเปลี่ยนบทบาท ให้ออกจากระบบก่อน

- ฐานเริ่มต้นคือ `sa_web_demo` บน `127.0.0.1:3306` คำสั่ง setup ต้องใช้บัญชี MariaDB ที่สร้างฐานและบัญชีเฉพาะฐานได้ ค่าเริ่มต้นคือ `root` สำหรับการติดตั้งแบบ local
- หากต่างจากค่าเริ่มต้น ให้ตั้ง `SA_DEMO_DB_PORT`, `SA_DEMO_DB_ADMIN_USER` และ `SA_DEMO_DB_ADMIN_PASSWORD` ใน shell ก่อนรัน setup ใช้ `SA_DEMO_PORT` เพื่อเลือกพอร์ตเว็บก่อน setup ครั้งแรก ตัวอย่าง PowerShell `$env:SA_DEMO_DB_PORT = '3307'`
- หากเว็บหา Chrome/Edge ไม่พบ ให้ตั้ง `CHROME_PATH` เป็น path ของโปรแกรมก่อนเปิดเว็บ ตัวอย่าง macOS คือ `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` เครื่องที่ใช้ Linux ตั้งเป็น path ของ Chrome หรือ Chromium ที่ติดตั้งไว้
- รัน setup ซ้ำได้โดยเก็บผลการซ้อมและวันนัดเดิมไว้ ชุดวันสาธิตใหม่ให้ใช้ MariaDB instance แยกที่ยังไม่มีฐาน `sa_web_demo` แล้วเลือกโปรไฟล์ใหม่ตามหัวข้อท้ายคู่มือ วันนัดและวันครบกำหนดจะนับจากวันที่ตั้งชุดนั้น
- `demo:start` ใช้ค่าจาก `.local/demo/runtime.env` และเปิดรับเฉพาะ loopback ตั้ง `SA_DEMO_MODE=0` ก่อนเริ่มเพื่อซ่อนปุ่มด่วนในชุด demo รหัสของบัญชีสาธิตสำหรับกรอกเองอยู่ในตัวแปร `SA_DEMO_SECRET` ในไฟล์ดังกล่าว
- ภาพ รายงานเดิม และลายเซ็นตัวอย่างมาพร้อมโปรเจกต์ ใช้งานแบบออฟไลน์ได้หลังติดตั้ง dependencies ลิงก์ลูกค้าเฉพาะเครื่องอยู่ใน `.local/demo/CUSTOMER-LINKS.md` ลิงก์ที่ใช้งานได้จาก seed มีอายุ 30 วันนับจากการตั้งชุด
- ตรวจชุดที่เพิ่งเตรียมด้วย `npm run demo:test` ขณะเว็บเปิดอยู่ คำสั่งนี้ตรวจปุ่มทั้งหก สถานะตัวอย่าง และสิทธิ์เปิดรูปในเบราว์เซอร์

## เตรียมชุดตรวจรับแยกจากชุดซ้อม

ให้เปิด MariaDB instance ที่ว่างสำหรับชุดนี้ ตัวอย่าง PowerShell ด้านล่างใช้พอร์ตฐาน `3319` และพอร์ตเว็บ `3011` คงค่า `SA_DEMO_PROFILE` เดิมในทุก Terminal ที่ใช้ชุดเดียวกัน ไฟล์ลิงก์ลูกค้าของตัวอย่างนี้อยู่ใน `.local/demo-acceptance/CUSTOMER-LINKS.md`

```powershell
$env:SA_DEMO_PROFILE = 'acceptance'
$env:SA_DEMO_DB_PORT = '3319'
$env:SA_DEMO_PORT = '3011'
npm run demo:setup
npm run demo:start
```

เมื่อต้องการให้ Edge เดินครบทุกเคสอัตโนมัติ ให้เปิด Terminal อีกอัน ตั้ง `SA_DEMO_PROFILE` เป็นชื่อเดียวกัน แล้วรัน `npm run demo:test:journeys` การทดสอบนี้ลงทะเบียนบ้านใหม่และเดินงานบนบ้านเคสทางเลือก จึงใช้กับชุดตรวจรับที่เตรียมแยกไว้และยังไม่ได้ซ้อม
