| ชุดงาน | สิ่งที่ทำงานได้ |

| QC | ลงทะเบียนบ้าน, เปิดรอบ, เพิ่ม/แก้/ลบจุดและรูปก่อน finish, ล็อกหลัง finish, รับงานเป็นชุด, รูปหลังซ่อม, ตรวจผ่าน/ส่งกลับแก้, นัดตรวจซ้ำ, พบจุดใหม่, ผู้ตรวจร่วม/รับรองคนเดียว, พร้อมขาย |
| คำขอ/นัด | ผูกลูกค้า/ลิงก์ 30 วัน, ยื่นเอง/ฝ่ายขายยื่นแทน, นัด/เลื่อนนัดในคำขอเดิม, มาถึงและเปิดรอบ |
| ก่อนรับมอบ | แจ้งจุด CUSTOMER/EXTERNAL, แยกประเภท, ซ่อม/รูป, PDF ภาษาไทยพร้อมรูปจาก storage, ติดตามสถานะ, ไม่ผ่านพร้อมเหตุผล/ส่งกลับแก้, ยอมรับ, เขียนหรือแนบลายเซ็น, ส่งมอบ |
| ไม่ขอตรวจ | ไปเซ็นรับมอบโดยไม่สร้างคำขอหรือรอบตรวจที่ไม่จำเป็น |

## ผลตรวจจริง

- HTTP + MariaDB: **35 scenario ผ่าน** ครบ 18 UC รวม validation, ไฟล์, concurrency, rollback, inactive/craft/role และข้อมูลข้ามบ้าน
- Browser: **16 กลุ่มการเดินงานผ่าน** ตั้งแต่ login จนเซ็นและ reload ตรวจ DB; **152 layout checks** (19 SCR รวม login × 8 widths)
- ฟอร์ม/สถานะเพิ่มเติม **38 การตรวจ** ที่มือถือ/desktop รวมเงื่อนไขพร้อมและยังไม่พร้อม ไม่พบ axe WCAG 2 A/AA/2.1 AA violations; error/retry/รักษาข้อมูลกรอก 3 กรณีผ่าน ไม่ใช่การรับรองการเข้าถึงทั้งหมดโดยผู้ใช้จริง
- PDF ตัวอย่างจากข้อมูล/รูปทดสอบสมมติ: A4 **595.92 × 841.92 pt แนวตั้ง** ฟอนต์ไทยอ่านได้และมีเลขหน้า
- Final production build/TypeScript ผ่าน; ESLint **0 error/0 warning**; Hallmark static + rendered login **0 fail/reflex/warning**
- Final smoke ทุก role ผ่าน: contrast เมนู **13.09:1**, ปุ่มหลัก **14.61:1**; login/read/logout ไม่เปลี่ยนทั้ง 9 ตารางธุรกิจ
- Semantic mapping **77/77 Q IDs** ใน `runtime-query-map.csv` แยกจากผล execute SQL ของ P1
- Source เดิม **179/179** และ info **4/4** hash ไม่เปลี่ยน ไม่เขียนรายงาน Word/PDF เดิมหรือ Figma

Workflow/form suites ผ่านก่อนปรับข้อความ สีเมนู และประกาศ cursor disabled รอบสุดท้าย ส่วนที่ปรับท้ายตรวจด้วย final production smoke/Hallmark ไม่มีการเปลี่ยน business service เพิ่ม ดูผลละเอียดใน `evidence/runtime-*.json`

## ให้ผู้ใช้ลองตรวจรับ

1. เดิน QC จากบ้านใหม่จนพร้อมขาย ให้ช่างรับงาน/แนบรูป ลองตรวจผ่านและส่งกลับแก้
2. สร้างลิงก์ลูกค้า เดินขอตรวจ นัด มาถึง แจ้งจุด แยกประเภท ซ่อม เปิด PDF ลองไม่ผ่าน/ซ่อมใหม่/ยอมรับ/เซ็น
3. ลองไม่ขอตรวจและเซ็น ตรวจข้อความยืนยันกับสถานะบ้าน
4. ดูมือถือ/desktop โดยเฉพาะช่องพื้นขาว กรอบค้นหาชั้นเดียว checkbox เข้ม ปุ่มข้อความขาว และผู้แจ้งสองปุ่ม

เมื่อรับ G2 จึงทำ P6: แก้ข้อพบ/regression, ทดลอง restore backup, ไฟล์หาย/storage เต็ม/การเชื่อมต่อขาดระหว่างบันทึก และ UAT ก่อน G3 ยังไม่อ้างว่าผ่าน recovery หรือพร้อม public deployment

ปัญหา MariaDB Windows ที่พบ วิธีหลีกเลี่ยง และข้อจำกัดการวินิจฉัยอยู่ใน `RUNTIME.md` และ `evidence/runtime-debug-ledger.json` ไม่ได้เปลี่ยนเวอร์ชัน/config XAMPP
